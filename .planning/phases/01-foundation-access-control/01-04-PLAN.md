| Boundary | Description |
|----------|-------------|
| client → GET /api/workspaces | Caller must only receive workspaces they are a member of |
| client → POST /api/workspaces | Only Admins may create; role is never client-supplied |

## STRIDE Threat Register (ASVS L1, block on high)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Information Disclosure | workspace list scoping | high | mitigate | List query filters by the caller's memberships (deny-by-default); unauthorized workspaces are absent from the response body — never filtered client-side (ORG-03) |
| T-04-02 | Elevation of Privilege | POST /api/workspaces | high | mitigate | Admin-only enforced server-side in the controller/guard; UI hiding the button is NOT the control (CLI/MCP/REST bypass the UI) |
| T-04-03 | Tampering | workspace name uniqueness race | medium | mitigate | `@@unique([tenantId, name])` DB constraint; conflict mapped to a 409-style result, not a check-then-insert (edge #4 backstop) |
| T-04-04 | Spoofing | role-string leakage | low | mitigate | Custom admin/editor/consumer roles defined before controller/UI code; better-auth default `member` never surfaced (Pitfall 3) |
</threat_model>
