| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Spoofing | login / session cookie | high | mitigate | better-auth httpOnly + secure + sameSite session cookies; `trustedOrigins` allowlist for the dev origin (RESEARCH Security Domain V3) |
| T-03-02 | Elevation of Privilege | sign-up DTO (mass assignment) | high | mitigate | Public Zod DTO contains only email+password, no `role` field (Pitfall 4); new users have zero memberships until an Admin grant (Plan 05) |
| T-03-03 | Information Disclosure | login error / user enumeration | medium | mitigate | Ambiguous login error copy; canon breadcrumb: credential-enumeration hardening is OWASP-auth canon (also covered by /gsd-secure-phase) — the bespoke part kept here is the deliberate login-vs-registration asymmetry |
| T-03-04 | Tampering | CSRF on state-changing auth routes | medium | mitigate | better-auth origin-checking via `trustedOrigins` + sameSite cookie defaults; no GET-based state changes (RESEARCH Security Domain) |
| T-03-05 | Spoofing | password hashing | high | mitigate | Delegated entirely to better-auth (scrypt-based); no hand-rolled crypto (canon — breadcrumb to /gsd-secure-phase) |
